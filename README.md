# AALK models

On-device AI models downloaded by AALK TRACKS on first use (Settings → Modelli AI). Every file is checked against the
SHA-256 in the app's catalog before use. Provenance, licences and export scripts: `third_party/models/LICENSES.md` in
the AALK TRACKS repository.

| Release | Files | Upstream | Licence |
|---|---|---|---|
| `deepfilternet3-v1` | `enc.onnx`, `erb_dec.onnx`, `df_dec.onnx` | DeepFilterNet3 official ONNX export, https://github.com/Rikorose/DeepFilterNet (`models/DeepFilterNet3_onnx.tar.gz`, main d375b2d8) | MIT or Apache-2.0 (H. Schröter) |
